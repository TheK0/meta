# LaTeX Paper Workspace

This directory is the working area for the manuscript draft.

Structure:

- `main.tex`: entry point for the paper draft
- `references.bib`: BibTeX database for verified citations
- `notes/`: supporting notes moved out of the repository root
- `neurips_official/`: downloaded official NeurIPS template package

Release artifacts under `outputs/` remain in place because they are generated benchmark outputs and are still referenced by project documentation.

Template note:

- As of `2026-03-23`, the latest publicly accessible official template on `neurips.cc` is the NeurIPS 2025 style package:
  `https://media.neurips.cc/Conferences/NeurIPS2025/Styles.zip`
- No public `NeurIPS 2026` style file was available at alignment time, so `main.tex` is aligned against the latest official public template.
